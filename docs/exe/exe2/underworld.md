## 裏網路 -> WWW 區域

### 前往WWW區域1
* **裏網路4** -> **WWW區域1**
::: tip 條件
1. **【晶片收集】**：資料庫需要達到130種或以上
2. **【星之證】**：完成表關後自動取得，在標題畫面會出現黃色「★」記號
:::

### 前往WWW區域2
* **WWW區域1** -> 擊敗**法老王人V1** -> **WWW區域2**
::: tip 條件
1. **【執照】**：持有S執照
2. **【等級】**：洛克人等級在70或以上
:::

### 前往WWW區域3
* **WWW區域2** -> 擊敗**燒夷彈人** -> **WWW區域3**
::: tip 條件
1. **【執照】**：持有SS執照
2. **【V3晶片】**：除了WWW區域之外，需要收集其他V3領航員晶片 
:::
