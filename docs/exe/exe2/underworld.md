# EXE 2 裏關要素

## WWW 區域

### 裏網路4
**路線**：**裏網路4** -> **WWW區域1**
::: tip 條件
1. 資料庫需要達到130種或以上
2. 完成表關後自動取得，在標題畫面會出現黃色「★」記號
:::

### WWW區域1
**路線**：**WWW區域1** -> 擊敗**法老王人V1** -> **WWW區域2**
::: tip 條件
1. 持有S執照
2. 洛克人等級在70或以上
:::

### WWW區域2
**路線**：**WWW區域2** -> 擊敗**燒夷彈人V1** -> **WWW區域3**
::: tip 條件
1. 持有SS執照
2. 除了WWW區域的領航員之外，需要收集其他領航員的V3晶片 
:::

### WWW區域3
::: tip 條件
1. 資料庫的標準晶片需要達到200種或以上
:::

### 真佛魯迪V1
::: tip 條件
1. 擊敗WWW的3位領航員後回到「WWW區域 1」的傳送點會出現 「真佛魯迪V1」
:::

## 執照

### S執照
::: tip 考驗條件&內容
**條件**：完成委託「尋人」至「為了男人的尊嚴」共6個委託任務 **(不計算特別任務)**。

**內容**：連續擊敗 10 波病毒。
::: 

### SS執照
::: tip 考驗條件&內容
**條件**：
1. 取得強者資料：(要打防護病毒) 花4000Z購買副晶片「開鎖」，之後去WWW區域1 解開和電算區域1 的連結盒子，進去解鎖紫色神秘資料取得強者資料

2. 回到公職廣場找考官，給他強者資料，他會告訴你有幫派受到戈斯巴魯影響，延生了「黑色領航員幫派」，考官會說第四位成員的位置，其後可從每位成員當中得知下一位在那裏：
    - 第四位 - 雅吉納區域2
    - 第三位 - 亞美羅帕區域3
    - 第二位 - 裏網路6
    - 第一位 - 裏長壽區域 (近商人附近)

**內容**：連續擊敗 20 波病毒
::: 


### SSS執照 (推理)
::: tip 考驗條件&內容
**條件**：
1. 洛克人等級80或以上 (一定要80級或以上才可以進行下一步)
2. 前往公職廣場找考官，會得到第一個提示，以下的地方要順次序去對話，因為每一個地方都會有下一個地方提示
   1. 海軍港咖啡廳的木板
   2. 奧電谷水壩有4棵樹的公職人員
   3. 飛機的駕駛倉的儀器
   4. 通往瞭望台的階梯的公職人員
   5. 亞美羅帕後巷垃圾箱
   6. 雅吉納廣場的「國寶房間」的領航員
   7. 美露家鋼琴的電腦的紫色領航員
   8. 爸爸的研究室 (要打氣力人，青蛙人，閘門人，閃電人，蛇人，高熱人，布魯斯)
3. 完成後可以回到公職廣場找考官

**內容**：連續擊敗 30 波病毒
::: 


## 彩斗型態
::: tip 條件&內容
**條件**：以S評級擊敗所有V3領航員

**內容**：在秋原町公園的小女孩可以確認那個領航員是S級
:::
