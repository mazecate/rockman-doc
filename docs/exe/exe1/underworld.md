# EXE 1 裏關要素

## 互聯網區域 11 - 16

### 互聯網區域11
**路線**：**互聯網區域10** -> **互聯網區域11**
::: tip 條件
1. 遇到的戰鬥不可逃跑
:::

### 互聯網區域12
**路線**：**互聯網區域11** -> **互聯網區域12**
::: tip 條件
1. 戰鬥結果的 **消滅等級** 不可低於 3 級。
:::

### 互聯網區域13
**路線**：**互聯網區域10** -> **互聯網區域13**
::: tip 條件
1. 遇到的戰鬥不可逃跑
:::

### 互聯網區域14
**路線**：**互聯網區域13** -> **互聯網區域14**
::: tip 條件
1. 需要在互聯網區域 13 獲得 10 張戰鬥晶片。
:::

### 互聯網區域15
**路線**：**互聯網區域14** -> **互聯網區域15**
::: tip 條件
1. 移動過程中的遇敵次數需在 7 次或以下。
:::

### 互聯網區域16
**路線**：**互聯網區域15** -> **互聯網區域16**
::: tip 條件
1. 戰鬥結果的 **消滅等級** 不可低於 4 級。
:::
