# EXE 1 裏關要素

## 互聯網區域 11 - 16 通行條件

::: info 前往 互聯網區域 12
* **路線**：互聯網區域 11 -> **互聯網區域 12**
* **條件**：戰鬥結果的一次消滅等級（Busting Level）不可低於 3 級。
:::

::: info 前往 互聯網區域 14
* **路線**：互聯網區域 13 -> **互聯網區域 14**
* **條件**：需在互聯網區域 13 累計獲得 10 張戰鬥晶片。
:::

::: info 前往 互聯網區域 15
* **路線**：互聯網區域 14 -> **互聯網區域 15**
* **條件**：移動過程中的遇敵次數需在 7 次或以下。
:::

::: info 前往 互聯網區域 16
* **路線**：互聯網區域 15 -> **互聯網區域 16**
* **條件**：戰鬥結果的一次消滅等級（Busting Level）不可低於 4 級。
:::
