## <a id="ch1"></a>第一章：遊戲開始 ～ 電波塔篇

### 【秋原町：微波爐火災與引導】
1. **取得PET**：遊戲開始後，調查熱斗房間書桌上的 **PET**，取得核心裝置，查看電子郵件。
2. **與媽媽對話**：下樓前往廚房，與媽媽對話，得知微波爐發生火災。
3. **首次上線**：走到廚房微波爐前，按下 **R鍵** 上線進入「微波爐的電腦」。
4. **戰鬥教學**：在微波爐電腦中推進，觸發與初階病毒的戰鬥教學。完成後發現發火程式損壞。
5. **拿零用錢**：離線回到現實，與客廳的爸爸對話，獲得 **500z**。
6. **電腦上線**：回到二樓熱斗房間，調查書桌上的**個人電腦（PC）**，按下 R 鍵上線。
7. **購買修復貼紙**：沿著網路骨幹前進到 **秋原區域3**，找到一隻**紫色的領航NPC**，花費 500z 購買「復原修正檔」。
8. **修復微波爐**：按下 R 鍵離線，下樓與客廳的爸爸對話，交出貼紙成功修復微波爐。

### 【電氣街：陰影人首度現身】
9. **全鎮大問候**：走到秋原町大街上，必須與以下所有人對話才會觸發捷運事件：公園裡的兩個小孩、迪卡歐、站在路邊的大姊姊、展示新PET的叔叔。
10. **前往電氣街**：所有人對話完後，走到秋原町捷運站前觸發劇情。搭電車前往 **「電氣街2丁目」**。
11. **音響上線**：一出站往前走，看見美露和雅伊朵在店門口。與她們對話後，調查她們前面的**大音響**並上線。
12. **與同伴對話**：在音響電腦中，找到蘿露（Roll）與格萊德（Glyde）的領航並與其對話，隨後離線。
13. **觸發異變**：在現實中再次與美露和伊朵對話，觸發劇情後前往電氣街廣場。
14. **前往廣場**：往左走到 **「電氣街廣場」** 觸發劇情(電波干擾事和舉辦比賽)後，回到 **「電氣街2丁目」**。
15. **尋找同伴**：在**大音響**並上線，大量路人的領航紛紛倒下，向前行觸發陰影人（ShadeMan）抓走蘿露的劇情。
16. **抓走蘿露**：前往**秋原區域3**觸發劇情陰影人（ShadeMan）抓走蘿露後，檢查郵件收到「雅伊朵的通行碼」。
17. **追上陰影人**：前往**都市區域2**經傳送點去都市區域1，再去到**電波塔的電腦1**發生劇情。
18. **前往廣場**：不能進入電氣街廣場和與研究員對話，回到 **「電氣街1丁目」** 發現鐵絲網沒有上鎖，前往廣場觸發電波干擾劇情。
19. **奪取耳機戰**：回到**電氣街2丁目**對**大音響**上線，在最裡面找到一隻**綠色的領航**並與其戰鬥，戰勝後獲得「耳機」，可抵抗超音波。
20. **電波塔上線**：調查電波塔的控制面板並上線，進入 **「電波塔的電腦1與2」**。
21. **雷達捕蝙蝠**：跟綠色程底對話得到「啟動資料A/B」，在限時 10 秒內抓出隱形蝙蝠（區域 1 抓 3 隻，區域 2 抓 4 隻），搜尋時必須全程按住 **B鍵進行奔跑**。
22. **陰影人首戰（劇情戰）**：調查電波塔基座的「音量調整鈕」，直接強制進入戰鬥。此時陰影人為劇情無敵（傷害皆為0），意即只要打中他數次即可。
23. **黑暗晶片**：去日暮屋找日暮先生查詢發生劇情，檢查郵件取得「迪卡歐的通行碼」。
24. **結束序章**：回家調查熱斗的床鋪睡覺，正式結束此事件。




## <a id="ch2"></a>第二章：第一回官方大賽 (電算巨蛋 / 市區大賽預選與本賽)

### 【第一階段：大賽預選三大委託】
1. **拿取門禁碼**：前往電氣街廣場，與中央的大叔對話，獲得重要進度道具「上文電器代碼」。
2. **大賽報名**：在電氣街2丁目冰箱上線，一路走到 **都市區域3**，尋找紫色機兵設置名稱並報名參加大賽。
3. **完成預選三大委託**：
   * **委託 ①** 與女人對話，答對提出的問題後，進行病毒 3 連戰。
   * **委託 ②** 與科學家對話尋找黃金竹節蟲，分別在**秋原町的公園樹上(竹節蟲母蟲)**和**雅伊朵家的熊公仔(竹節蟲公蟲)** 。
   * **委託 ③**：與外國人對話後，幫他尋找小矮兵村，首先去**秋原區域2**尋找不斷行路的紫色機兵，其後去**都市區域2**下層尋找綠色機兵，最後在 **電氣街2丁目(由1丁目經鐵絲網門口去)** 上層液晶螢幕上線，擊敗裡面的惡意病毒並拿回「研究資料」。
4. **晉級正賽**：完成三個委託後回到廣場找大叔觸發劇情，前往新地方 **「電算巨蛋」**。走上 2 樓與金髮的大會負責人對話，正式通過預選並開始大賽分組。

### 【第二階段：大賽對手分支事件（隨機抽選）】
1.走到**巨蛋等侯室**與外國人對話觸發劇情。
通過預選進入會場後，根據版本與周目進度隨機抽取對手事件。通關後方可返回會場進行正賽：

#### <a id="gutsman"></a>🔴 紅日限定：氣力人（Gutsman）
1. **文字謎題綁架案**：劇情自動出現迪卡歐的弟弟（デカオの弟）被誘拐的事件，且歹徒指名要熱斗去救。隨後收到一封文字謎郵件。
2. **尋找解謎提示**：
   * 前往電氣街的電波塔前，找一個**老爺爺**對話要到下一個提示（仍是文字謎）。
   * 前往 **都市區域3** 的商店後方，找綠色領航對話要到第三個提示（還是文字謎）。
   * 返回電算巨蛋，調查賽場中間的**花籃**，隨即接到歹徒的電話。
   * 跑回秋原町公園，調查**松鼠雕塑**，發現關鍵的搜捕線索。
3. **開啟搜捕程式**：前往電波塔上線進入「電波塔電腦2」，在先前遇見陰影人的地方，與 **右起第 3 個保安程式（程式君）** 對話。隨後再度接到電話，要求去網路收集 1 到 5 的數字數據（DATA）。
4. **找尋五大邪惡領航**：上網尋找各區域出現的不良領航以收集數據：
   * **數據1**：在「秋原區域1」直接對話拿取。
   * **數據2**：在「秋原區域3」，必須花 **1000z** 向其購買。
   * **數據3**：在「都市區域1 (Town Area)」，必須答對 5 題問答。請依序選擇選項：**【3】個人終端機 ➔ 【3】長頸鹿 ➔ 【1】繩紋電器 ➔ 【2】七子 ➔ 【3】章魚燒店**。
   * **數據4**：在「都市區域2」，對方要求交換一張 **「バブルショットR（泡泡槍R）」**。（※可回熱斗房間上線，到秋原區域2的商店花 800z 提前買好）。
   * **數據5**：在「都市區域3」，對話後直接開戰將其擊碎。
5. **正賽解鎖**：集齊全數數據後，前往現實中的電波塔前觸發劇情，擊敗病毒（ガルーEX）。最後返回巨蛋會場擊敗氣力人，紅日版本將解鎖**氣力靈魂（Guts Soul）**。

#### <a id="fireman"></a>🔴 紅日限定：火焰人（Fireman）
1. **肚子餓與修爐子**：與操作者火野健一打過招呼後熱斗會肚子餓。前往巨蛋左邊的章魚燒攤位買東西吃，火野也會過來。談話中得知火野曾幫過老闆娘，並用眼色支走了小混混。隨後爐子突然壞掉，熱斗上線解決病毒，但爐子徹底損壞。
2. **追蹤火焰人**：在巨蛋休息室與外國人對話獲得「火焰ID。前往 **秋原區域3** 用 ID 打開水藍色電子門，發現火焰人正和兩個古怪的傢夥密謀。上去通知火焰人回去修爐子，接著回章魚燒店對話。
3. **場地炸彈危機**：進入會場準備比賽時，火野突然透露為了讓 WWW 組織復活，他吩咐手下在賽場安裝了炸彈。但他隨後發現章魚燒店的老闆娘也在觀眾席，急忙吩咐手下停止，卻沒人聽從。
4. **手動拆除五處炸彈**：熱斗必須在巨蛋內部找出 5 個定時炸彈並解除：
   * 休息室**桌上的皮包** ➔ 走廊的**自動販賣機** ➔ 走廊的**接待櫃檯（受付）** ➔ 正面入口的**花籃** ➔ 走廊**屏風擋住的角落**。
5. **拆除小遊戲與病毒戰**：全解除後回到賽場，得知威力最大的炸彈已裝在對戰機台裡。調查機台裝置，火野會解釋解除有 2 個步驟：首先玩小遊戲，**在數字倒數到 0 前按 A 鍵拍打解除 20 個小炸彈**；之後再次調查裝置，打倒裡面的病毒即可徹底解除。
6. **正賽對決**：危機解除後與火焰人對戰，勝利後紅日版本解鎖**火焰靈魂（Fire Soul）**。

#### <a id="aquaman"></a>🔵 藍月限定：流水人（Aquaman）
1. **舟子哭泣事件**：與流水人對決前，向巨蛋外走會自動觸發城戶舟子因沒錢而哭泣的一連串事件。全看完後，與巨蛋門口的雙胞胎之一對話獲得道具（氧氣瓶）。
2. **網路搜救與氧氣限制**：上線進入 **都市區域2** 尋找流水人。（※此時**畫面右上角會出現氧氣表限制**，如果氧氣即將耗盡，必須中途進入地圖上帶有「房子標記」的個人主頁空間來恢復氧氣）。
3. **現實拿鑰匙**：跟著流水人逃跑的方向一路追到秋原區域的電子門前，發現門被鎖死。離線後去詢問剛剛的雙胞胎，得知舟子去了電氣街。前往電氣街找她拿取鑰匙，回網路開門說服流水人回去。
4. **正賽對決**：返回巨蛋進行比賽，勝利後藍月版本解鎖**流水靈魂（Aqua Soul）**。

#### <a id="numberman"></a>🔵 藍月限定：數字人（Numberman）
1. **日暮大叔棄權？**：準備比賽時，工作人員前來通知數字人棄權了。熱斗前往秋原町的日暮商店一探究竟。
2. **網路發傳單**：為了幫忙，熱斗拿取了「日暮屋的傳單」並上線進入網路。在各大地圖、個人主頁空間（如秋原區域、都市區域、微波爐、大音響等）只要見到領航或程式君就發放傳單，**發滿 10 張以上**即可回店裡找店員奈奈子（ナナコ）報告。
3. **搜救數字人**：前往 **都市區域1** 的綠色電子門前，會聽到數字人在裡面喊救命。離線並回日暮屋向奈奈子拿取「日暮屋電腦鑰匙」，再次回到網路打開第一道扇門。
4. **密碼解鎖大門**：進入後會遇到第二扇大門，需要根據提示輸入正確密碼：
   * 「1・31、2・28」（月份天數）➔ **331**
   * 「147、258」（九宮格數字規律）➔ **369**
   * 「救護車」➔ **119**
   * 「"Hi" = " He???"」➔ **110**
   * 「x=3, y=4, xyx=???」➔ **343**
   * 「12、10、8」（偶數遞減）➔ **642**
   * 「三個圓」➔ **000**
   * 「三條線」➔ **111**
   * 「梯子」➔ **845**
   * 「50+50+50」➔ **150**
5. **正賽對決**：救出數字人後離線，回到日暮屋發生劇情，回去電算巨蛋進行比賽。勝利後藍月版本解鎖**數字靈魂（Number Soul）**。

#### <a id="sparkman"></a>👥 共通對手：火花人（Sparkman）
1. **晶片資料夾被鎖死**：看過比賽表後收到郵件，在會場入口與一個戴帽子的青年對話。青年假裝是 PET 修理人員，卻趁機將熱斗的晶片資料夾鎖死成一堆垃圾晶片。他溜走時掉落了一張「紙片」，有7條問題。
   * 1: JO-MON的數量
   * 2: 秋原區域2的廣場之中分出去的主要街道有幾條？
   * 3:「電腦蝙蝠」總共有幾隻？
   * 4: 目前在電波塔的電腦中領航員的數量
   * 5: 都市區域2的坡道的數量
   * 6: 都市區域3中指著上方或下方的三角形記號的數量
   * 7: 秋原町中熊玩偶的數量
2. **尋找解鎖工匠**：前往電氣街2丁目，先與廣場通道附近的**大姊姊**對話打聽。接著與冰箱前的 **老爺爺（店長）** 對話尋求幫助。
3. **紙條組合與密碼判斷**：老爺爺表示需要密碼才能解鎖。打開「重要道具」查看紙條開頭的字句，密碼共有固定三組：
   * 提示字為「在都市區域...」➔ **1863546**
   * 提示字為「上文電器的數量...」➔ **7374262**
   * 提示字為「液晶螢幕的...」➔ **9681345**
   * *💡 方法：可先嘗試改動第1位數字，直到老人說「……7……1……」（代表7位數中有1位正確），以此方法推算出出完整密碼。*
4. **正賽對決**：輸入正確密碼解鎖**晶片資料夾**，返回電算巨蛋會場好好教訓閃光人。

#### <a id="topman"></a>👥 共通對手：陀螺人（Topman）
1. **撿到電導陀螺**：走出巨蛋在樓梯處看到老爺爺（匠轉助）和孫子吵架。隨後對地上的**陀螺上線**，清除裡面的病毒。離線後獲得「電導陀螺」。
2. **網路同好會的考驗**：前往電氣街2丁目將陀螺還給老爺爺，熱斗決定幫忙修復他的領航。前往秋原町公園與老爺爺們的「網路戰鬥同好會」對話。老人們答應幫忙，但條件是洛克人必須去都市區域答對他們的領航提出的問題。

   * **都市區域1 (Town Area) 西側**：答對問題獲得「秘傳數據1」（若答錯，必須在現實中幫老人搥背才能拿）。

3. **鏟雪小遊戲與點火**：在夏羅屋外活動時右上角會顯示體溫計，體溫降完會扣血，可隨時回屋內恢復。先調查擋路的巨大雪堆，去街上的民宅（或狗拉雪橇旁的房子）調查獲得「鏟子（ショベル）」。前往 4 處天線按 **B鍵連打** 完成鏟雪，上線進入天線電腦消滅所有雪人，最後調查中央的たいまつ（電腦火把），消耗上述對應晶片將其點燃。
4. **正賽對決**：4 處天線全部點燃後夏羅天氣恢復。返回亞美羅帕巨蛋會場，在漫天大雪的戰場上擊敗作惡的寒冷人。

#### <a id="kendoman"></a>👥 共通對手：劍道人 (Kendoman)
1. **前往亞弗利克特訓**：名人穿著劍道服衝出來，稱自己被推選為非洲代表，要求熱斗去亞弗利克找劍道人打招呼。搭機前往亞弗利克，對**努波波神像上線**進入亞弗利克區域找到劍道人。

   * **特訓網點位置**：**雅吉納區域**（道なり進）、**亞美羅帕區域北側**、**夏羅區域**。
   * **武術格擋打法規則**：在限時內依據劍道機器的防守姿勢變換按下對應方向鍵 ＋ A 鍵攻擊，將其體力減至 0：
     * 對方高舉劍 ➔ 按 **下 ＋ A**（打下段）
     * 對方抱胸 ➔ 按 **右 ＋ A**（打中段）
     * 對方防守下方 ➔ 按 **上 ＋ A**（打上段）
     * 對方高舉劍並大喊 ➔ 按 **左 ＋ A**（進行防禦格擋）
3. **解救獅子人質與正賽**：通過挑戰並把證書交給劍道人。返回賽場發現劍道人沒來。大賽暫停，立刻飛回亞弗利克，得知暴徒控制了獅子抓走人質。繞到村子北東側對**獅子雕塑上線**，在獅子電腦中尋找並**破壞全部 4 個惡意控制裝置**。救出人質後回巨蛋進行正賽。

#### <a id="normalnavi03"></a>👥 共通對手：普通領航員 (炸彈足球)
1. **足球 PK 賽挑戰**：普通領航跑來向熱斗提出炸彈足球 PK 大賽的挑戰。

## <a id="ch6"></a>第六章：最終決戰：宇宙中心與小行星的電腦

### 【第一階段：通訊干擾解除任務】
1. **世界大賽獲勝後**：頒獎典禮被打斷，熱斗被直升機直接接往 **ANSA（宇宙航空局）總部**。
2. **橫幅圖像** ： 檢查郵件，取得「旅館的橫幅圖像」。
3. **ANSA 2 樓會議室**：與利卡爾博士及爸爸（光祐一爾）開會，得知小行星正快速逼近地球，同時全球網絡遭到了黑色物質（隕石前兆）的嚴重堵塞。
4. **取得發信器與吉加晶片**：從利卡爾博士手中接過發信器和爸爸手中接過強力的 **`極級晶片（Giga Chip）- 紅日版：流星紅日 / 藍月版：藍月射線`** 及解鎖用道具。

### 【第二階段：全球網絡大清理任務】
4. **解除通訊設備干擾**：為了導引小行星，必須搭飛機前往三個海外地圖並上線調查：

   * **夏羅（シャーロ）**：進入寒冷科學中心，調查中央的大型主機電腦並上線。
5. **取得城鎮鑰匙資料**：解決了干擾問題，去亞美羅帕區域找"**亞美羅帕公職人員**對話" (在夏羅回到亞美羅帕區域），取得「都市鑰匙資料」

### 【第三階段：小行星的電腦迷宮（しょうわくせいの電脳1〜4）】
8. **ANSA 1 樓**：洛克人被同伴們的愛與力量救回，熱斗趕回 ANSA 與 1 樓中央的大叔對話。

## <a id="side_quest"></a>【支線任務：太陽少年聯動支線】

### ☀️ 任務前置條件
* **開啟條件**：主線必須推進至可以進入 **地下網路（裏インターネット / Undernet）** 的中後期階段。
* **準備資金**：預留至少 **10,000z**。

### 步驟
1. **前往裏網路4**：在亞弗利克神像上線，前往 **裏網路4**，會遇見《我們的太陽》主角**太陽少年強哥（ジャンゴ）**。
2. **接受委託**：與強哥對話，他會拜託熱斗與洛克人協助他尋找並徹底消滅吸血鬼陰影人（ShadeMan）的任務。
3. **前往裏網路2**：前往 **裏網路2** 的入口處，找到一個**紫色的領航NPC**並與其對話，獲取陰影人下落的關鍵情報。
4. **購買道具**：接著前往 **裏網路6**，在區域下層找到一隻黑色領航NPC。與他對話並花費 **10,000z** 買下任務核心道具(陽光感測器)。
5. **淨化**：回到 **裏網路4** 與 **太陽少年強哥（ジャンゴ）** 對話觸發劇情。此處需要配合強哥的太陽光線機制將其擊潰。

* **報酬**：成功打敗陰影人後，強哥會贈送極其珍貴的聯動限定晶片 **「太陽槍3」** 作為報酬。
* **隱藏 BOSS 觸發**：完成此任務後，未來只要在網路世界重新回到 **裏網路4**，地圖上將會隨機低機率遭遇極具挑戰性的隱藏強敵——**陰影人 SP（ShadeMan SP）**。
* <span style="color:yellow;">**⚠️ 注意事項**：調查吸血鬼棺材可以獲得「星雲通行碼」。此道具是**打開「骷髏門（ドクロの扉）」**。</span>
